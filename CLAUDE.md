# Projeto H — instruções para o Claude

Sistema hoteleiro (Next.js 16 + Prisma 7 + PostgreSQL no Docker). Visão geral, comandos e
organização em `README.md`; o que cada fase entregou em `docs/FASE-*.md`.

## Salvar no GitHub (combinado com o dono do projeto)

- Ao **concluir uma fase** (código pronto, `npm test`, `npm run typecheck` e `npm run lint`
  sem erros, e testada no navegador), fazer **commit e `git push`** para o repositório
  privado no GitHub, sem perguntar.
- Não enviar trabalho pela metade ou com teste falhando. Fora do fim de fase, só quando o
  dono pedir.
- Nunca versionar `.env` (senhas). Conferir antes de cada commit.

Português, resumos amigáveis e com pouco jargão.
